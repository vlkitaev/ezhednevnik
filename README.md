# Ежедневник

Простое Android-приложение: список дел по дням, без интернета и без сторонних библиотек.

- листание дней стрелками, тап по дате — календарь, долгий тап — вернуться на сегодня
- добавление, редактирование (тап по тексту), удаление, отметка о выполнении
- данные хранятся локально в SharedPreferences

Сборка: GitHub Actions -> вкладка Actions -> последний запуск -> Artifacts -> `ezhednevnik-debug-apk`.
APK отладочный, подписан debug-ключом: ставится на телефон после разрешения установки из неизвестных источников.
